# 단어의 서재 · JLPT N1 압축판

1,000개 고유 표제어 · 20 Days × 50개로 구성된 독립형 정적 웹앱/PWA입니다.

## PWA 설치

### iPhone / iPad
1. GitHub Pages로 배포한 주소를 **Safari**에서 엽니다.
2. 공유 버튼(□↑)을 누릅니다.
3. **홈 화면에 추가**를 선택하고 추가합니다.
4. 홈 화면의 `단어의 서재 N1` 아이콘으로 실행합니다.

iOS에서는 Safari 공유 메뉴를 통해 홈 화면에 추가합니다. 앱 실행 후에는 전체 화면 형태로 열립니다.

### Android / 데스크톱 Chrome
1. 배포한 HTTPS 주소로 접속합니다.
2. 상단 **앱 설치** 버튼 또는 브라우저 메뉴의 **앱 설치**를 선택합니다.

## 오프라인 학습
최초 온라인 접속 시 서비스 워커가 앱 화면, 매니페스트, 아이콘, 어휘 데이터 파일을 캐시합니다. 캐시가 완료된 이후에는 인터넷 연결이 없어도 앱 화면을 열 수 있습니다. 업데이트 배포 시 서비스 워커 캐시 버전이 바뀌면 새 파일을 내려받습니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소를 생성합니다.
2. 이 ZIP을 풀고 **폴더 안의 파일 전체**를 저장소 최상위(root)에 업로드합니다. `.github/workflows/pages.yml`도 포함해야 합니다.
3. 저장소 **Settings → Pages**에서 Source를 **GitHub Actions**로 설정합니다.
4. **Actions** 탭에서 `Deploy static site to GitHub Pages` 작업이 성공했는지 확인합니다.
5. Pages에 표시되는 HTTPS 주소로 접속합니다.

## 구성
- `index.html`: 앱 화면, 1,000개 어휘 데이터, 플립·키보드 조작
- `words.json`, `words.csv`, `words.tsv`: 별도 어휘 데이터 파일
- `manifest.webmanifest`: PWA 앱 이름·아이콘·실행 모드
- `sw.js`: 오프라인 캐시 및 앱 셸 제공
- `icons/`: 192px / 512px 앱 아이콘
- `.github/workflows/pages.yml`: GitHub Pages 자동 배포 설정

## 조작
- 카드 클릭 / Space / Enter: 카드 뒤집기
- ←: 이전 카드
- →: 다음 카드
- 입력창에 커서가 있을 때는 키보드 단축키가 작동하지 않습니다.

## 학습 기록
외움·복습·회독 정보는 브라우저의 localStorage에 저장됩니다. 같은 브라우저에서는 유지되지만 다른 기기와 자동 동기화되지는 않습니다.

## 어휘 선정 및 한계
N1 명사·동사·형용사·부사 자료를 주요 기반으로 하고 독해 활용도가 높은 어휘와 표현을 선별했습니다. JLPT는 공식 어휘 목록을 공개하지 않으므로 공식 출제 목록이나 출제 보장 자료는 아닙니다.

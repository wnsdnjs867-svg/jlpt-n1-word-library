# 단어의 서재 · JLPT N1

800개 · 하루 50개 · 총 16일. 일본어 표제어를 보고 읽기와 뜻을 떠올린 다음 카드를 뒤집으세요. 선택한 카드에는 단어가 자주 붙는 표현이나 비슷한 말과의 차이가 표시됩니다.

| 순서 | 학습 범위 |
| --- | --- |
| Day 01–05 | 최우선 250개. 논설문 논리 전개, 추상어, 문맥에 따라 뜻이 달라지는 부사·동사 |
| Day 06–12 | 핵심 350개. 논설·기사 어휘, 관용표현, 복합동사와 용법 |
| Day 13–16 | 보강 200개. 주요 어휘를 익힌 뒤 폭을 넓히는 데 쓰는 카드 |

한 달 계획이라면 새 카드 16일을 마친 뒤 남은 14일에 복습 카드를 돌리세요. 정답을 볼 때 뜻과 함께 연결되는 조사나 표현도 읽어 보세요. 예를 들어 `結果を踏まえる`는 `を`를, `事実に基づく`는 `に`를 함께 익히면 좋습니다.

## 기존 GitHub Pages 단어장 업데이트

1. ZIP을 풉니다. 압축 파일 이름에 `950`이 남아 있어도 이 버전의 앱은 800개입니다.
2. GitHub Desktop에서 기존 단어장 저장소를 선택하고 Repository → Show in Finder를 누릅니다.
3. 압축을 푼 **폴더 안의 파일**을 저장소 최상위에 복사하고 같은 이름의 파일을 교체합니다.
4. GitHub Desktop에서 Commit → Push origin을 누릅니다. 기존 Pages 워크플로가 배포를 처리합니다.
5. 온라인 상태에서 앱을 열고, 화면에 800개와 16 DAYS가 표시되는지 확인합니다. 이전 화면이면 앱을 한 번 더 열거나 브라우저를 새로고침하세요.

같은 기기·같은 사이트 주소에 남아 있는 950개 판 또는 1,000개 판 기록은 동일 어휘의 외움·복습 표시를 가져옵니다. Day 구성이 바뀌어 Day 진도와 회독은 새로 시작합니다. 오프라인 학습에는 업데이트 뒤 한 번 온라인 접속이 필요합니다.

카드 클릭 / Space / Enter로 뒤집고 ← / →로 넘길 수 있습니다. `words.json`, `words.csv`, `words.tsv`에는 앱과 동일한 데이터가 들어 있습니다.

## 선정 기준

기존 950개에서 기초 어휘, 한 분야에 치우친 항목, 표기와 조사만 달라진 중복 카드를 줄였습니다. 의미를 결정하는 부사, 논설에서 자주 만나는 추상어, 함께 쓰이는 대상에 따라 구별할 필요가 있는 동사·유의어를 보강했습니다. 우선순위는 한 달 학습을 위해 정한 편집 판단입니다. JLPT 운영 기관은 공식 어휘 목록을 공개하지 않습니다.
